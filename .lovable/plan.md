## Нови комплекти (6 бр.)

Всеки използва съществуващи `CatalogDocument` имена от каталога (ще проверя точните имена при build):

1. **`predvaritelen-dogovor-imot`** *(real_estate)* — Предварителен договор за покупко-продажба, нотариален акт (чернова), декларации по чл. 264 ДОПК.
2. **`pulnomoshchno-paket`** *(other → нова група "Пълномощни")* — Генерално пълномощно, пълномощно за банка, пълномощно за МПС, нотариална заверка чек-лист.
3. **`razvod-paket`** *(other / family)* — Споразумение за развод по взаимно съгласие, искова молба, споразумение за издръжка.
4. **`roditelski-prava-paket`** *(other / family)* — Споразумение за родителски права, режим на лични отношения, издръжка.
5. **`zaem-pari-paket`** *(other)* — Договор за заем, разписка, запис на заповед, погасителен план.
6. **`deklaratsii-paket`** *(other)* — Декларация по ЗМИП, декларация по чл. 264 ДОПК, декларация за съгласие, GDPR съгласие.
