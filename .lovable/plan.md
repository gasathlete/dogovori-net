
# Меню „Инструменти" + правни калкулатори

## Цел

Заменяме чипа „ЗЗД · ТЗ · ЗУТ" в хедъра с dropdown „Инструменти", който отваря набор от практични правни калкулатори под единен интерфейс. Целта е двойна: (1) полезност за съществуващи потребители, (2) SEO трафик за термини като „калкулатор обезщетение чл 222", „калкулатор лихва за забава", „нотариална такса калкулатор" (10 000+ търсения/мес общо, KDI 0–15).

## 1. Хедър промени

- Премахваме чипа `ЗЗД · ТЗ · ЗУТ` (`src/components/Header.tsx`, редове 98–125 desktop + 180–188 mobile).
- На негово място — бутон **„Инструменти"** с икона `Calculator` (lucide), който отваря popover (shadcn `Popover` или `DropdownMenu`).
- Popover съдържанието: 2‑колонен grid с иконки + кратко описание на всеки калкулатор + линк „Виж всички" към `/tools`.
- На мобилно — секция „Инструменти" в hamburger менюто с разгъващ се списък.

## 2. Нов рут /tools (хъб)

- `src/pages/Tools.tsx` — единна страница с 8 калкулатора като карти. Кликване отваря модал/inline forma със същия unified UI shell.
- Header: H1 „Правни калкулатори", H2 „Безплатни инструменти за бързи изчисления по българското законодателство".
- SEO: canonical `/tools`, JSON‑LD `CollectionPage` + `ItemList` с 8‑те калкулатора.
- Sitemap: добавя се `/tools` + `/tools/:slug` в `scripts/build-sitemap.ts` → `sitemap-static.xml`.

## 3. Унифициран интерфейс

Един `CalculatorShell` компонент с три зони:
1. **Входни полета** (отляво/горе) — auto‑validate, EUR навсякъде.
2. **Резултат** (отдясно/долу) — голяма цифра + breakdown стъпка по стъпка с препратки към закон.
3. **Правно основание** (footer на карта) — чл./закон + линк към lex.bg.

Всеки калкулатор експортира: `{ slug, title, description, icon, schema (zod), compute(input): Result, legalBasis }`. Един рендеринг компонент обработва всички 8 — гарантира визуална консистентност и SEO еднообразие.

- Резултатите се закръгляват и форматират чрез `Intl.NumberFormat('bg-BG', { style: 'currency', currency: 'EUR' })`.

## 5. SEO на ниво калкулатор

Всеки калкулатор има и отделен URL `/tools/:slug` за дълга опашка ключови думи:
- `<title>` ≤ 60 ch: `{Име} – безплатен онлайн калкулатор 2026 | Dogovori.net`
- `<meta description>` ≤ 160 ch
- H1 = името на калкулатора
- 250–400 думи SEO съдържание под калкулатора (как се изчислява, пример, FAQ 3 въпроса)
- JSON‑LD: `SoftwareApplication` + `FAQPage` + `BreadcrumbList`
- Вътрешни линкове към свързани шаблони от `/blanki` и `/shablon/:slug`
