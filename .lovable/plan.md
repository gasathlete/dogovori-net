
# Преструктуриране на картите в /plans

Целта: всяка карта на план да изглежда чиста и компактна, а функциите да са групирани в **разгъваеми категории** с **главен акцент** (водеща функция), които се отварят с приятна, дигитална анимация. Всички надписи — на български.

## Какво виждаме сега
Картата изброява 8–14 функции като плосък списък → препълнено, трудно за сканиране.

## Нова структура на картата (визуално)

```text
┌──────────────────────────────────────────┐
│  [икона]  Предприемач     [НАЙ-ПОПУЛЯРЕН]│
│           19.90 €/мес                    │
│                                          │
│  ✦ Акцент: „AI преговорна стратегия"     │ ← водеща полза
│                                          │
│  ▸ 🧠  Интелигентност       →  GPT-5     │ ← свита: икона + категория + акцент
│  ▸ 📄  Документи и шаблони  →  600+      │
│  ▸ 🛡  Сигурност и достъп   →  Парола    │
│  ▸ ⚙️  Автоматизации        →  Архивиране│
│  ▸ 👥  Екипна работа        →  —         │
│  ▸ 🛟  Поддръжка             →  Приоритет│
│                                          │
│  [ Активирай Предприемач  → ]            │
└──────────────────────────────────────────┘
```

При натискане на ред категорията се „разгръща" надолу с плавна анимация на височина + поетапно появяване на отделните точки и леко златно проблясване — да усеща се „дигитално и приятно за натискане".

## Категории (фиксиран ред, едни и същи за всички планове)

| Икона | Категория (бг) | Главен акцент — пример |
|---|---|---|
| Brain | Интелигентност | Безплатен: базов асистент · Професионалист: GPT-4o · **Предприемач: GPT-5 + Преговори** · Екип: GPT-5 за всички |
| FileText | Документи и шаблони | Безплатен: 5 операции · Професионалист: 50/мес · Предприемач: 150/мес · Екип: 100/място |
| Shield | Сигурност и достъп | Професионалист: парола за линкове · Предприемач: + одит на действия · Екип: готовност за SSO |
| Zap | Автоматизации | Професионалист: **Масово сваляне (ZIP)** · Предприемач: напомняния · Екип: общи процеси |
| Users | Екипна работа | Безплатен/Професионалист/Предприемач: — · **Екип: общо работно пространство + роли** |
| LifeBuoy | Поддръжка | Безплатен: общност · Професионалист: имейл · Предприемач: приоритетна · Екип: посветен мениджър |

Ако някоя функция не пасне в категория → отива в „Други възможности" (показва се само при наличие).

## Файлове

1. **Нов** `src/lib/planCategories.ts`
   - Дефиниция `PLAN_CATEGORIES` (id, български етикет, икона, ключови думи на български).
   - `categorize(features) → { categoryId, items, highlight }[]`.
   - Чисто типизиран, без странични ефекти.

2. **Нов** `src/components/plans/PlanCategoryAccordion.tsx`
   - Един разгъваем ред: икона + български етикет + чип с акцент отдясно + стрелка.
   - Анимация с framer-motion: `height: auto`, поетапно (40ms) появяване на точките, златна линия отдолу при отворено.
   - Достъпност: `aria-expanded`, клавиатурна навигация, само една отворена категория в карта (state в родителя).

3. **Нов** `src/components/plans/PlanHeroBenefit.tsx`
   - Един ред над разгъваемите категории: ✦ + кратък български текст — водещата полза на плана.
   - Текстове (български) per план:
     - Безплатен: „Започни без карта"
     - Професионалист: „Масово сваляне и защитени линкове"
     - Предприемач: „AI преговорна стратегия с GPT-5"
     - Екип: „Общо работно пространство за фирмата"

4. **Промяна** `src/pages/Plans.tsx`
   - Заменяме плоския `<ul>` (редове 214–221) с:
     - `<PlanHeroBenefit planId={plan.id} />`
     - `<div>{categorize(plan.features).map(c => <PlanCategoryAccordion … />)}</div>`
   - Картата запазва рамка, бутон, „НАЙ-ПОПУЛЯРЕН" значка.

5. Без промени по: `usePlans`, БД, таблицата за пълно сравнение, ЧЗВ, секцията за пакети операции.

## Визуални детайли (за „дигитално усещане")
- Свит ред: `border-hairline/60` → hover `border-gold/40`, преход 200ms.
- Икона в малък `rounded-lg` квадрат `bg-foreground/5`; при отворено → `bg-gradient-gold/15 text-gold`.
- Чип с акцент: `text-[10px] uppercase tracking-wider`, `bg-gold/10 text-gold border border-gold/30`.
- Стрелката ротира 180° при отваряне, 250ms.
- При първо отваряне — златна „вълна" (1px линия) пробягва отляво надясно (600ms).
- По подразбиране всички категории са затворени, за да се вижда цялата структура.

## Мобилно поведение
- Същата структура.
- Тап-зони ≥44px.
- Чипът с акцент се скрива под 360px ширина (остават икона + категория + стрелка).

## Технически бележки
- `framer-motion` вече се ползва.
- Категоризацията се изчислява веднъж per план чрез `useMemo`.
- Аналитика: `trackEvent("plans_category_expanded", { plan, category })` при отваряне.

## Извън обхвата
- Без промени по БД / RLS.
- Без редизайн на ЧЗВ, hero блок, превключвателя месечно/годишно, доверителната лента.
- Без промяна на цените, бутоните за действие, секцията за пакети операции.
